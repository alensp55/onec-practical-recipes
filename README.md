# Практические рецепты 1С

Независимые примеры на нейтральных структурах данных.

## Рецепты

- `relative-hierarchy` — относительная иерархия для СКД;
- `multiline-log-dedup` — дедупликация многострочных сообщений;
- `safe-document-refill` — безопасное перезаполнение строк документа;
- `transactional-state-change` — смена состояния после блокировки и повторного чтения;
- `batched-query` — ограничение размера параметра запроса;
- `claim-lease-queue` — конкурентный захват задания с ограниченной арендой;
- `paged-selection-processing` — обработка больших наборов страницами по курсору;
- `temporary-storage-transfer` — безопасная передача подготовленного результата через временное хранилище.

## Проверка

```powershell
python -m unittest discover -s tests -v
```
