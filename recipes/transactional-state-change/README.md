# Транзакционная смена состояния

`StateTransition.bsl` повторно читает состояние только после блокировки записи внутри транзакции. Это закрывает окно
между предварительной проверкой и записью. Повтор той же операции идемпотентен: если новое состояние уже установлено,
запись не выполняется.

Передайте объект `Хранилище` с методами:

- `Заблокировать(Ключ)` — установить исключительную управляемую блокировку по полному ключу записи;
- `ПолучитьСостояние(Ключ)` — прочитать состояние после блокировки;
- `ЗаписатьСостояние(Ключ, Состояние)` — записать изменение.

Реализация хранилища должна использовать один источник данных и одинаковый ключ для блокировки, чтения и записи.
Проверяйте права, RLS и допустимость перехода до вызова либо расширьте `ПроверитьПереход()` правилами своей модели.
