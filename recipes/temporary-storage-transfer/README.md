# Передача результата через временное хранилище

Рецепт разделён на чистую подготовку и платформенный адаптер:

- `PrepareTemporaryResult.bsl` копирует только разрешённые поля в версионированный нейтральный пакет;
- `TemporaryStorageAdapter.bsl` на сервере сохраняет пакет с привязкой к форме и возвращает клиенту адрес.

Клиент должен хранить адрес в реквизите формы и передавать его только штатному серверному вызову чтения. После
успешного получения `ИзвлечьИУдалитьРезультат()` удаляет значение. Не принимайте произвольный адрес из внешнего ввода
и не помещайте в пакет значения, которые недоступны или не сериализуются в требуемом клиентском контексте.

Привязка к уникальному идентификатору формы ограничивает срок жизни значения. Для повторного чтения удалите вызов
удаления и задайте явное правило очистки, иначе временное хранилище будет расти до завершения сеанса или формы.
