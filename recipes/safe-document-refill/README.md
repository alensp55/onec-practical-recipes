# Безопасное перезаполнение существующего документа

Рецепт разделяет две задачи:

1. `ОпределитьДействие()` выбирает сценарий по режиму и количеству найденных документов.
2. `ЗаменитьЗатронутыеСтроки()` создаёт новую таблицу строк, не меняя исходную коллекцию.

Поддерживаются режимы:

- `Перезаполнить`;
- `СоздатьНовый`;
- `Пропустить`.

Если найдено несколько документов, результат всегда `ПропуститьНеоднозначность`. Автоматически выбирать первый
документ небезопасно.

В реальной конфигурации запись выполняйте на сервере:

1. Повторно найдите документ внутри транзакции.
2. Установите управляемую блокировку по ключу поиска.
3. Зафиксируйте состояние проведения.
4. Замените только строки с переданными ключами.
5. Выполните штатный перерасчёт документа.
6. Запишите документ и восстановите требуемое состояние проведения.
7. При исключении отмените транзакцию и сообщите пользователю конкретный документ.

Метаданные, типы ключей, права и повторное проведение зависят от конфигурации и намеренно отсутствуют в примере.
