# Очередь с claim/lease

`ClaimLeaseQueue.bsl` захватывает задание после блокировки и повторного чтения внутри короткой транзакции. Аренду
может продлить тот же владелец; другой обработчик получает задание только после истечения срока. Состояние с другим
статусом, например завершённое, повторно не захватывается.

Передайте объект `Хранилище` с методами `Заблокировать()`, `Прочитать()` и `Записать()`. Все три операции должны
использовать одинаковый полный ключ задания. Поля нейтрального состояния: `Статус`, `Владелец`, `АрендаДо`, `Версия`.

Используйте серверное время из одного источника. После внешнего эффекта завершайте задание отдельной атомарной
операцией с проверкой владельца и версии. Lease уменьшает риск навечно зависших заданий, но не гарантирует exactly-once:
обработчик должен быть идемпотентным либо записывать ключ выполненного эффекта.
