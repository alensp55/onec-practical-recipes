# Выбранный узел как корень иерархии СКД

Штатная иерархическая группировка может достраивать родителей выбранного элемента до корня справочника.
Если отчёт должен начинаться именно с выбранного узла, передайте СКД отдельный внешний набор иерархии.

`BuildRelativeHierarchy.bsl` принимает таблицу со строковыми ключами `Ключ` и `Родитель` и возвращает таблицу:

- `Ключ`;
- `Родитель`;
- `Уровень`.

У выбранного корня `Родитель` очищается. В результат включаются только корень и его потомки.

В СКД нужно:

1. Создать внешний набор с теми же типами ключа и родителя, что используются в основном наборе.
2. Связать основной набор с полем `Ключ` собственной иерархии.
3. Связать `Родитель → Ключ` внутри иерархического набора.
4. Передавать пустую типизированную таблицу для вариантов отчёта, которые эту иерархию не используют.
5. Проверить направление связей, каждый вариант отчёта и смену вариантов в одной открытой форме.

В примере используются строки, чтобы модуль не зависел от конкретного справочника. В конфигурации задайте типы
колонок явно.
