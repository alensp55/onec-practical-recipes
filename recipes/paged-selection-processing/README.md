# Постраничная обработка выборки

`PagedSelection.bsl` хранит в памяти только одну страницу. Поставщик выполняет keyset-запрос: выбирает первые
`РазмерСтраницы` строк с ключом больше переданного курсора и сортирует их по ключу. Поле `Ключ` должно быть уникальным,
непустым и строго возрастающим между страницами.

Обработчик получает страницу только после проверки порядка ключей. Делайте обработку страницы идемпотентной: сбой
после внешнего эффекта может привести к повтору страницы при следующем запуске. Не удерживайте одну транзакцию на весь
набор. Если исходные данные меняются, используйте зафиксированную верхнюю границу ключа или другой снимок выборки.

Не используйте смещение строк: при конкурентных изменениях оно может пропускать или повторять записи и обычно
становится медленнее на дальних страницах.
