# Выполнение запроса пакетами

`BatchQuery.bsl` ограничивает размер массива, передаваемого в параметр запроса, и объединяет результаты в одну
`ТаблицаЗначений`. Порядок пакетов соответствует порядку входного массива; сортировку итоговых строк задавайте в
запросе или выполняйте после объединения.

Подготовьте `Запрос`, в котором параметр используется как список в условии `В(&Ключи)`, и вызовите
`ВыполнитьЗапросПакетами()`. Размер пакета выбирайте по профилю данных и СУБД. Пустой вход не выполняет запрос и
возвращает пустую таблицу без колонок.

Рецепт не открывает транзакцию: чтение больших наборов внутри долгой транзакции может удерживать лишние блокировки.
Если требуется единый снимок данных, определите транзакционные требования отдельно для используемой СУБД.
