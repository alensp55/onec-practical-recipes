# Дедупликация многострочных ошибок

Сравнение только заголовков скрывает новую причину ошибки. Поэтому однозначно выделенные сообщения нужно
сравнивать целиком: заголовок вместе с продолжением.

`LogDeduplicator.bsl` принимает уже разобранные блоки текста. Разбор зависит от формата конкретного журнала:
метки времени, уровня, идентификатора операции или другого надёжного признака начала сообщения.

Если границы сообщений неоднозначны, передайте `ГраницыОднозначны = Ложь`. Тогда применяется старое построчное
сравнение. Оно менее точно, но не склеивает несколько разных ошибок в один блок.

Функции не изменяют входные массивы.
